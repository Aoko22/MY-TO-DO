# 📝 To-Do List

A simple and interactive To-Do List web application built using **HTML, CSS, and JavaScript**.

## ✨ Features

* Add new tasks
* Mark tasks as completed
* Delete individual tasks
* Clear all tasks
* Track completed tasks
* Display the current day, date, and time

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript

## 🎯 Purpose

This project was created to practice **JavaScript DOM manipulation, event handling, functions, and dynamic webpage updates**.
